The original article is openly available under Creative Commons Attribution; consult the linked publisher notice for the exact terms governing the supplement and preserve author attribution when redistributing. The supplied data edition remains unverified as explained in DATA_PROVENANCE.md. No new license ownership is claimed over experimental data.

MATLAB source and numerical/documentation arrangements were written for this project using the stated mathematical conventions and references. No published source text, publisher figures, MATLAB example implementation, external mesh or original experiment video is bundled. Simulation geometry is an illustrative project-generated model. Dependencies are base MATLAB and Java available with the target MATLAB installation; optional host verification used SciPy and MISS_HIT but they are not runtime requirements.

Generated files must retain the distinction between measured parent data, conditional reconstruction and synthetic sensor variants. Citation of equations or data does not constitute validation of the reconstructed motion or the chosen augmentation ranges.
